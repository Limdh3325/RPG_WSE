- 유지할 설계 의도:
  - 각 Region은 전용 OS worker 스레드를 보유하며 오직 이 스레드만 RegionWorld 상태를 변경(Single Writer).
  - Tokio 비동기 런타임과 동기 Worker 스레드 간 crossbeam/tokio bounded channel 분리.
  - Ingress 채널 포화(4096초과) 시 `try_send` 비차단 거부 및 `RouteError::ServerBusy` 반환.
  - 틱 지연이 `MAX_ACCUMULATED_DRIFT_MS`(500ms) 초과 시 catch-up 버스트 폭주(death spiral)를 막기 위해 기준 시각 재설정.
  - 연속 3틱 이상 lag 발생 시 `RegionHealth::Degraded` 전이, 지연 해소 시 `RegionHealth::Healthy` 자동 복구.
  - 영속 ACK는 Ingress 명령보다 우선 처리되며, 영속 저장 지연 중에도 타 엔티티 시뮬레이션 틱은 차단 없이 지속.
  - Graceful shutdown drain 시 미정산된 모든 durable loot intent를 안전하게 회수하여 0 유실 보장.
- 위임: 완료 후 서브에이전트 적대적 코드 리뷰(`delegate_task`) 수행.
