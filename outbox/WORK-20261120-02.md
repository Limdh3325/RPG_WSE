## 9차 병합 판정 지적사항 조치 결과

1. **P1 — 마지막 체크포인트 손상이 새 지역으로 처리됨 조치**: `snapshot.rs:load_latest_verified_snapshot`에서 스냅샷 행이 존재하는데 모두 체크섬 손상(corrupted)된 경우 `Ok(None)` 대신 `Err(PersistenceError::CorruptedSnapshot)`으로 즉시 실패하도록 수정. `test_per_019_only_corrupted_snapshot_fails_recovery` 테스트 추가 및 통과.
2. **P1 — 미지원 금융 이벤트 버전이 복구 성공으로 처리됨 조치**: `recovery.rs:DomainEventRow`에 `schema_version`, `rules_version`을 추가하고 SELECT 및 리플레이 진입 시 현재 버전 대조 검증을 수행하여, 미지원/비호환 이벤트 버전 발견 시 `Err(PersistenceError::IncompatibleVersion)`으로 즉시 거부하도록 수정.
3. **M3 게이트 — 서버 재시작 경로 연결 조치**: `apps/game-server/src/main.rs` 기동 시 DB 연결 후 마이그레이션 실행 및 기본 리전 복구(`RecoveryManager::recover_region`)를 호출하여 영속화된 상태(체크포인트 + 이벤트 리플레이)를 성공적으로 복원하고 lease를 확보하는 완전한 서버 복구 파이프라인 연결.
4. **P2 — DB 연결 실패 진단에 비밀값이 포함될 수 있음 조치**: `durable_transactions.rs` 및 `snapshot_recovery.rs` panic 메시지에서 민감 정보(DATABASE_URL 원문)를 제거하고 에러 메시지만 출력하도록 수정.
